# Selah Kids prototype

Kids' Bible prototype (ages 4 to 9): story path, illustrated read-aloud stories, memory verses, quizzes and stickers.

- `stories.js`: the 12 stories (original retellings; memory verses from the public-domain World English Bible)
- `art.js`: SVG picture kit used for every illustration
- `app.js`: screens, read-aloud, quiz, sticker book, grown-ups corner
- `shell.html`: page and styles
- `index.html`: built single file (the three scripts inlined into `shell.html`)

Not wired into the Capacitor or Electron builds yet; whether it ships as its own app or a mode inside Selah is still open.
